# 対応銀行 CSV フォーマット仕様

プリセット方式（ADR-0005）を採用。各銀行のパーサーはコードで実装する。

---

## りそな銀行 (`preset_key: resona`)

- **文字コード**: Shift-JIS
- **スキップ行**: 1行（ヘッダ行）
- **入金フィルター**: `レコード区分 = "明細"` かつ `取引名 = "入金"`
- **合計行の除外**: `レコード区分 = "合計"` を除外

| 列インデックス | 列名 | 使用 |
|---|---|---|
| 0 | レコード区分 | フィルター用 |
| 13 | 取引名 | フィルター用（入金/支払） |
| 14 | 取扱日付　年 | 日付（年） |
| 15 | 取扱日付　月 | 日付（月） |
| 16 | 取扱日付　日 | 日付（日） |
| 17 | 金額 | 入金額 |
| 19 | 摘要 | 振込名義（例: `振込　ﾀﾅｶ ｷﾐﾋﾄ`） |

**注意**: 日付は3列分割。`YYYY-MM-DD` に結合して使用。

---

## みずほ銀行 (`preset_key: mizuho`)

- **文字コード**: UTF-8
- **形式**: メタデータブロック（キー・バリュー形式）+ 空行 + ヘッダ行 + データ行
- **スキップ行**: 可変。空行の次の行がヘッダ行。コードでメタデータブロックを読み飛ばす。
- **入金フィルター**: `お預入金額`（列3）が空でない行のみ

| 列インデックス | 列名 | 使用 |
|---|---|---|
| 0 | 明細通番 | 未使用 |
| 1 | 日付 | 日付（形式: `YYYY.MM.DD`） |
| 2 | お引出金額 | 未使用（空 = 入金） |
| 3 | お預入金額 | 入金額 |
| 4 | 残高 | 未使用 |
| 5 | お取引内容 | 振込名義（例: `振込　タナカ　キミヒト`） |

**注意**: 全角カナを使用。マッチング時は半角カナに正規化して比較。

---

## 横浜銀行 (`preset_key: yokohama-bank`)

- **文字コード**: Shift-JIS
- **スキップ行**: 1行（ヘッダ行）
- **入金フィルター**: `お預り金額`（列2）が空でない行のみ（`取引区分`が`振込`または`入金`）

| 列インデックス | 列名 | 使用 |
|---|---|---|
| 0 | 取扱日付 | 日付（形式: `YYYY年M月D日`） |
| 1 | お支払金額 | 未使用（空 = 入金） |
| 2 | お預り金額 | 入金額（形式: `¥105,000`） |
| 3 | 取引区分 | フィルター参考（振込/出金/入金） |
| 4 | 残高 | 未使用 |
| 5 | 摘要 | 振込名義（例: `ﾀﾅｶ ｷﾐﾋﾄ`） |

**注意**: 日付形式が非標準。金額に `¥` と `,` が含まれるため除去が必要。

---

## 振込名義の照合正規化

全銀行共通の照合ルール：

1. 両辺（`PaymentProfile.transfer_name` と摘要）を**半角カナに正規化**して比較
2. 摘要の先頭にある `振込　` 等のプレフィックスは除去してから比較
3. アルファベット表記（銀行の文字数制限で名前が切れる場合あり）は**前方一致**で照合

---

## 口座振替（集金サービス）対応 — 保留中

SMBC等の口座振替サービスを使う組合では、銀行明細に個人名が出ないため上記の名義照合が機能しない。振替サービス業者の集金明細CSVを別途インポートする方式を検討中。SMBCのデータフォーマット確認待ち（2026-05-26 保留）。
