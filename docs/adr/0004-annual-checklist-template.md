# ADR 0004: AnnualChecklist に標準テンプレートを提供しカスタマイズ可能にする

## Status
Accepted

## Context
日本のマンション管理組合には消防設備検査・エレベーター定期検査など法律で義務付けられた定期業務がある。これらを組合が1から入力する場合、初期設定の負荷が高く、抜け漏れのリスクもある。一方、マンションの規模・設備・築年数によって該当する点検項目は異なる。

## Decision
システム側で標準 ComplianceTask テンプレートを事前定義し、Organization のオンボーディング時に「該当する・しない」を選択する形で初期チェックリストを生成する。その後、組合固有の業務をカスタム追加できる。テンプレートはシステムアップデートで追加・修正可能とする。

標準テンプレートに含む項目（初期）：
- 消防設備検査（年1〜2回）
- 建築設備定期検査（年1回）
- エレベーター定期検査（年1回）
- 貯水槽清掃・水質検査（年1回）
- 特定建築物定期調査（3年ごと）
- 排水設備清掃（年1〜2回）
- 管理組合定期総会（年1回）
- 理事会（任意頻度）

## Consequences
- **メリット**: オンボーディング時の入力負荷を大幅削減。法定点検の抜け漏れ防止。業界知識をプロダクトに埋め込むことで競合との差別化になる。
- **デメリット**: テンプレートのメンテナンスが必要。法改正・条例変更への追随が発生する。
- **境界**: テンプレートは「参考」であり、法的な義務の正確性についてはSaaS側は保証しない旨を明記する。
