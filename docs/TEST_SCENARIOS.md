# テストシナリオ

## 前提・共通事項

- テスト用メールアドレスは `+` エイリアスで使い分ける（例: `admin+test@example.com`）
- 各シナリオ開始前に DB をリセットするか、専用の組合を新規作成して行う
- ロール: `admin`（管理者）/ `vice_president`（副理事長）/ `treasurer`（会計）/ `board_member`（理事）/ `auditor`（監査）/ `resident`（住民）
- 「canEdit ロール」= admin / vice_president / treasurer

---

## シナリオ 0：テスト環境準備

| # | 操作 | 期待結果 |
|---|---|---|

| 0-2 | 組合名を入力して組合を作成 | ダッシュボードへ遷移、管理者として登録される |
